# Working in EVM Reconstruction Lab

- Preserve captured chain evidence and submitted Standard JSON sources.
- Use `build/` for experiments and generated artifacts.
- Report executable, full-bytecode, metadata, behavioral and explorer results separately.
- Never describe a mined selector collision as an original function name.
- Use stock compilers for final comparisons. Record compiler versions and settings.
- Run the tests and case reproduction documented in CONTRIBUTING.md after tool changes.
- Keep analysis offline unless collecting explicitly requested chain evidence.
- No deployment or transaction broadcasting is part of this repository's workflow.
