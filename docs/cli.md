# CLI reference

Run `uv run evm-lab --help` for commands. JSON is written to stdout; errors go to
stderr. Exit 0 means success, 1 means a comparison mismatch or an exhausted mining
range, and 2 means invalid input or an operational error.

## Inspect and compare

`inspect HEX_FILE` detects compiler metadata and lists instruction-aligned PUSH4
constants. It does not infer dispatch control flow. `disassemble HEX_FILE` emits
a linear opcode listing with offsets and truncated immediate flags; embedded
data can look like instructions. Opcode names do not establish fork validity.

`compare ORIGINAL CANDIDATE --require exact|executable` compares raw hex files.
Metadata is parsed conservatively and reported separately. Length-only
differences are reported at the end of the shorter executable, not as a match.

## Signatures and calldata

```sh
uv run evm-lab selector 'transfer(address,uint256)'
uv run evm-lab decode 'approve(address,uint256)' @build/approve-calldata.hex
uv run evm-lab mine-name 0x12345678 '(address)' --start 0 --attempts 100000
```

Signatures must use canonical ABI types (`uint256`, not `uint`). Tuple arrays
are supported by the decoder. A selector match does not establish the original
name or disambiguate every candidate ABI. The ABI decoder may accept trailing
data; this command is not a transaction-validity proof.

The portable miner searches `recovered_<decimal-counter><suffix>` and returns a
resume offset. A 32-bit preimage can require billions of trials, so the Python
implementation is mainly a reference and a small-search tool. For the optional
Apple GPU implementation, see [tools/README.md](../tools/README.md). Neither
miner discovers the original function name.

## Collection

Set an RPC endpoint in `ETH_RPC_URL` or choose another variable with `--rpc-env`.
Do not paste provider secrets into documentation or committed files.

```sh
uv run evm-lab collect 0xec6fc9be2d5e505b40a2df8b0622cd25333823db \
  --block finalized \
  --deployment-tx 0xa733d91ddbf7acc28db5e21cb66ebf3cdaee2acca1c9427dc160793505e63a2d \
  --output build/captured
```

The output directory must be new. Collection uses the block number returned by
the initial lookup and checks its hash again before saving. It records RPC
evidence, not proof of provider honesty. It never broadcasts a transaction.

## Compile and verify

The Node script accepts literal Standard JSON and a contract identifier:

```sh
node scripts/compile.cjs \
  cases/wintermute-curve-balancer/standard-input.json \
  build/wintermute-curve-balancer/compiled.json \
  src/Executor.sol:Executor 0.8.19+commit.7dd6d404

uv run evm-lab verify cases/wintermute-curve-balancer \
  --artifact build/wintermute-curve-balancer/compiled.json \
  --output build/wintermute-curve-balancer
```

The checked-in npm lock installs solc 0.8.19. Its JavaScript `tmp` dependency is
overridden to 0.2.7 for dependency fixes; the solc compiler binary is unchanged
and the case is checked after compilation. For another case, explicitly install
the desired stock `solc` package in a separate location and set `SOLC_MODULE` to
its absolute module directory. The script checks the expected version. Required
outputSelection entries are `evm.bytecode`, `evm.deployedBytecode`, and
`evm.methodIdentifiers`; add ABI, storage layout and IR as needed. The script
does not silently change compiler settings or patch generated bytecode.

When editing a new candidate, refresh its template's literal source contents:

```sh
uv run evm-lab build-input candidate/standard-input.json \
  --root candidate --output build/candidate-input.json
```

For recorded cases, `verify` requires checked-in source text to equal the literal
submission input. It executes both constructors, verifies the original runtime,
compares creation/runtime bytes and checks the entire supplied selector map.
The default constructor environment is deliberately limited; see
[match definitions](match-levels.md).
